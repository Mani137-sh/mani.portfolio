Featured Research

Design of Acquisition Module for the NavIC Receiver Chip

My research focuses on designing a complete ASIC implementation of the GPS/NavIC acquisition engine using Verilog RTL. The architecture performs efficient satellite acquisition through PRN code generation, carrier generation, code phase search, Doppler search, MAC based correlation, and peak detection. The complete design has been implemented, verified, prototyped on FPGA, and synthesized using Cadence Genus and Innovus.
